# GitHub Actions for Authors

A beginner-friendly manual and static site for using GitHub Actions to
auto-build book sites, run checks on pushes, deploy to GitHub Pages, and
handle secrets safely — written in plain English, step by step.

Written for authors, nurses-turned-writers, and anyone who wants automation
without the jargon.

## What's inside

- `docs/github-actions-for-authors.md` — the full beginner manual with
  step-by-step YAML examples you can copy and paste.
- `docs/worksheet.md` — a printable workflow worksheet to fill in by hand.
- `site/` — a static HTML version of the manual you can open in any browser.
- `LICENSE` — MIT License, copyright Asdale Dynamics, LLC.

## No secrets, ever

This repository intentionally contains no `.github/workflows` directory, no
API keys, no passwords, and no personal data. The YAML examples use placeholder
names so you can safely copy them into your own repository.
